C · 面试官可问 Likely follow-ups

Q1: 这和 DeepTeam 什么关系？ / How does this relate to DeepTeam?
DeepTeam 是可选的红队/攻击生成引擎；本仓库是编排层：场景包 × 归因 Judge × 双循环资产 × 报告。默认 BuiltinHeuristicEngine，无 API Key 可离线跑通。 DeepTeam is an optional attack engine; this repo owns orchestration.
Q2: Attribution Judge 输出什么？ / What does the attribution Judge emit?
每个失败 case：error_locus（落点）+ attributed_rule（规则）+ fix_suggestion（修复建议），导出 badcases.jsonl 并保留原始对话；审核后转成回归资产仍需后续实现。 Each fail gets locus + rule + fix → badcase bank.
Q3: Pairwise 如何对抗位置偏差？ / How do you fight position bias?
多轮随机交换 A/B 展示顺序，winner 映射回原始 a/b；只保留「轮次一致 ∧ 标签匹配」进入 Golden Set（宁缺毋滥）。 Randomize display order, remap winners; keep only consistent ∩ label-matched.
