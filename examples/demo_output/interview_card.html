核心叙事（背这四句）

  1. 引擎可换，编排是我的 — Heuristic 默认可离线；DeepTeam 可选。
  2. 左环对抗 — Pack → Engine → Trace → Attribution（locus / rule / fix）→ badcase。
  3. 右环资产 — gold / error / challenge 驱动下一轮；评测与尺子一起迭代。
  4. Pairwise 三坑 — 位置随机 remap；多轮一致=置信度；precision > coverage（例 6/25）。
